# Frontend

React 19 + Vite UI for Library AI.

## Quick start

```bash
cd frontend
npm install
cp .env.example .env         # VITE_API_BASE_URL=http://localhost:8000
npm run dev
```

Open http://localhost:5173

## Production

Deployed on Vercel. Set `VITE_API_BASE_URL` in project settings before build.

See [../docs/DEPLOYMENT.md](../docs/DEPLOYMENT.md) and [../docs/FRONTEND.md](../docs/FRONTEND.md).

## Scripts

```bash
npm run dev       # development
npm run build     # production build
npm run lint      # ESLint
```
